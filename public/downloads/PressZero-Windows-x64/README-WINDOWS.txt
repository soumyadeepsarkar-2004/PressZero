PressZero Desktop Instrument (Windows x64 Portable Edition)
Zero-Knowledge Exact-KB Image Reducer & Biometric Cropping Suite
================================================================================

OVERVIEW:
PressZero for Windows is a standalone, portable desktop instrument engineered for
high-throughput offline batch compression, signature bleaching, and biometric photo
formatting without ever uploading files to any remote server.

HOW TO RUN:
1. Double-click "PressZero.exe" or run "Launch-Offline.bat".
2. The application opens in a dedicated, isolated native window frame.
3. You can disconnect your network (Wi-Fi / Ethernet) completely: PressZero operates
   100% in local device memory with zero bytes outbound network egress.

SECURITY & VERIFICATION:
- Zero telemetry egress: Does not send analytics, telemetry, or file data over the network.
- No Administrator privileges required: Runs portably from any folder or USB drive.
- Pure client compute: Utilizes your local multi-core CPU threads via Web Workers.

SYSTEM REQUIREMENTS:
- Windows 10 (64-bit) or Windows 11 (64-bit)
- Standard WebView2 / Chromium engine (built into Windows 10 and 11)
- Minimum 2GB RAM

SUPPORT & UPDATES:
For web studio and progressive web app install: https://presszero.app
