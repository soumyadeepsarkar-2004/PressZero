========================================================================
PRESSZERO FOR MACOS — UNIVERSAL DISTRIBUTION (APPLE SILICON & INTEL)
========================================================================

SYSTEM REQUIREMENTS:
- macOS 11.0 (Big Sur), macOS 12 (Monterey), macOS 13 (Ventura),
  macOS 14 (Sonoma), macOS 15 (Sequoia), or later.
- Architecture: Apple Silicon (M1/M2/M3/M4) & Intel (x86_64).

INSTALLATION INSTRUCTIONS:
Option A (One-Click):
  Double-click "Install-PressZero.command". It automatically installs
  PressZero to your /Applications folder and clears any quarantine flag.

Option B (Manual):
  1. Drag "PressZero.app" into your "/Applications" folder.
  2. Launch PressZero from Spotlight (Cmd + Space) or Launchpad.

GATEKEEPER VERIFICATION:
If macOS shows an unnotarized developer prompt on first launch:
Right-click "PressZero.app" and select "Open", or run in Terminal:
  xattr -cr /Applications/PressZero.app

ZERO-KNOWLEDGE PRIVACY GUARANTEE:
All image bisection, signature bleaching, and biometric cropping
execute locally inside memory via Web Workers. 0 bytes network egress.
